# Lanika

Браузерная игра на чистых HTML, CSS и JavaScript. Без фреймворков и внешних библиотек.

## Запуск

Открыть `index.html` в браузере или поднять статический сервер:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Структура

```
index.html      разметка страницы: HUD, <canvas>, кнопки управления
css/style.css   оформление страницы и канваса
js/input.js     модуль ввода: состояние клавиш, оси движения
js/game.js      класс Game: игровой цикл, обновление состояния, отрисовка
js/main.js      точка входа: создание игры и привязка кнопок
```

## Управление

Стрелки или WASD — движение квадрата по полю.
