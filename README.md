# Lanika

Браузерная игра на чистых HTML, CSS и JavaScript. Без фреймворков и внешних библиотек.

## Запуск

Открыть `index.html` в браузере или поднять статический сервер:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Структура

```
index.html      разметка страницы: HUD, квадратное поле <canvas>, экранные клавиши
css/style.css   оформление страницы, адаптивное квадратное поле, стиль клавиш
js/input.js     слой логических действий (left/right/down/go) для клавиатуры и экранных клавиш
js/game.js      класс Game: игровой цикл, обновление состояния, отрисовка, масштабирование канваса
js/main.js      точка входа: создание игры, привязка клавиш, реакция на ресайз
```

## Управление

- ← / A — влево
- → / D — вправо
- ↓ / S — вниз
- GO (Space / Enter) — запуск игрового хода

На мобильных — только экранные клавиши под полем: слева ← и ↓, справа → и GO. Свайпы не используются.
